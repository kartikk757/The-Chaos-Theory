# The Chaos Theory

Streamlit app for exploring and comparing SPHEREx observations. The app lives in [`chaozzz/`](chaozzz/README.md).

Run it from the repository root:

```bash
pip install -r chaozzz/requirements.txt
streamlit run chaozzz/app.py
```

The app can also be deployed from Streamlit Community Cloud using `chaozzz/app.py` as the entrypoint.
