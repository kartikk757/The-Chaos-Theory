# The Chaos Theory

An independent Streamlit app for exploring genuine SPHEREx observations. The application source, setup instructions, and scientific limitations are documented in [`chaozzz/README.md`](chaozzz/README.md).

Run it from the repository root:

```bash
python -m pip install -r chaozzz/requirements.txt
streamlit run chaozzz/app.py
```

Streamlit Community Cloud uses `chaozzz/app.py` as the entrypoint. The app is not an official NASA or Caltech/IPAC product and makes no discovery claim.
